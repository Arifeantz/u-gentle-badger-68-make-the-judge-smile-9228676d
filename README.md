A tiny Node 22 program (no dependencies, no network) that writes one warm line — a baker giving away a cracked-crust croissant free at seven in the morning — to `/output/entry.txt`, deterministically, every run: "At seven this morning the baker next door slipped me the last warm croissant — its crust had cracked, he said, so it couldn't be sold, only eaten."

## Run it

```sh
node main.ts
```
